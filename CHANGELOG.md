# Changelog

All notable changes to SpiritVale Drops Overlay are documented here.

## 1.0.0 — 2026-08-11

### Initial public release

- Packet-based rare-drop overlay
- Own-drop ownership filtering
- Rare-drop sound notifications
- Drops, Grind, and History tabs
- Grind session summaries
- Daily rare-drop statistics and history
- Profiles and per-profile sound filters
- Custom sound packs with Default fallback
- Portable settings under `data/`
- Application logs under `data/logs/`
- Remembered window position, size, and active tab
- Global `Ctrl + Alt + O` overlay toggle
- Portable Windows x64 release
