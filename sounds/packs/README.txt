SpiritVale Drops Overlay — Sound Packs

Built-in/default sounds stay exactly where they already are:
  sounds/card_boss.mp3
  sounds/card_normal.wav
  sounds/gem_boss.mp3
  sounds/gem_normal.wav
  sounds/essence.wav
  sounds/eggs.wav
  sounds/lure_boss.wav

Custom packs go under:
  sounds/packs/<PACK NAME>/

Example:
  sounds/packs/Anime/card_boss.mp3
  sounds/packs/Anime/essence.wav

A custom pack only needs the files you want to replace.
If a file is missing from the selected pack, the overlay automatically
falls back to the built-in file in sounds/.

Supported override filenames:
  card_boss.mp3
  card_normal.wav
  gem_boss.mp3
  gem_normal.wav
  essence.wav
  eggs.wav
  lure_boss.wav

The old test files epic.wav and rare.wav are not part of the sound-pack system.
