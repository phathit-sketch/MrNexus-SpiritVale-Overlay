# SpiritVale Drops Overlay v1.0.0

First public release by **MrNexus**.

## Highlights

- Rare-drop audio notifications
- Own-drop filtering
- Grind tracker and session summary
- Rare-drop history and daily statistics
- Profiles and sound filters
- Custom sound packs
- Portable configuration and logs
- `Ctrl + Alt + O` to hide/show the overlay without stopping capture

## Requirements

Npcap must be installed before packet capture can work.

## Install

Download `SpiritValeDropsOverlay-v1.0.0-win64.zip`, extract it, then run:

`bin/SpiritValeDropsOverlay.exe`

No installer is required.
