SpiritVale Drops Overlay — แอปเดียวจบ (capture + overlay รวมกัน)
================================================================

ตอนนี้รวมทุกอย่างเป็น process เดียวแล้ว — ไม่ต้องเปิด 2 terminal / ไม่ต้องใช้ start-overlay.bat อีก

================================================================
[A] สำหรับเรา (คนทำ) — ทดสอบ + build เพื่อแจก
================================================================

เตรียมครั้งเดียว (ในโฟลเดอร์ overlay-app):
  1) คัดลอกโฟลเดอร์ sounds/ ของโปรเจกต์ เข้ามาไว้ใน overlay-app/  (ให้มี overlay-app/sounds/*.wav|*.mp3)
       ไฟล์ที่ต้องมี: lure_boss.wav, eggs.wav, card_boss.mp3, card_normal.wav, gem_boss.mp3, gem_normal.wav, essence.wav
  2) bun install
       (@kar-mi ดึงจาก GitHub Packages — ใช้ token จาก .npmrc ที่ root โปรเจกต์อัตโนมัติ
        ถ้าไม่เจอ token ให้ก็อป .npmrc ที่ root มาวางใน overlay-app/)

ทดสอบ (dev) — คำสั่งเดียวจบ:
  bun run dev
     -> เปิดหน้าต่าง overlay + จับแพ็กเก็ต + เสียง พร้อมกัน (ต้องมี Npcap + อยู่ในเกม)

Build เป็นตัวแจก (.exe / win-x64):
  bun run build
     -> ได้ผลลัพธ์ใน dist/artifacts/  (โฟลเดอร์แอป win-x64 พร้อมแจก)
     -> zip โฟลเดอร์นั้นส่งให้เพื่อน

หมายเหตุ (สำคัญ):
  - source ถูก bundle+ฝังในไบนารี คนทั่วไปเปิดอ่าน .ts ไม่ได้ (แต่คนตั้งใจแกะยังได้ — JS กัน 100% ไม่ได้)
  - ถ้า build แล้วเสียงไม่เล่น = path ของ sounds/ ในตัว build ไม่ตรง บอกได้ เดี๋ยวปรับ resolveSound ให้
  - ถ้า build error ตรง capture (native Npcap) ส่ง log มา

================================================================
[B] สำหรับเพื่อน (คนใช้)
================================================================

  1) ติดตั้ง Npcap:  https://npcap.com  (ตอนติดตั้งใช้ค่า default ได้)
  2) แตก zip แล้วดับเบิลคลิกไฟล์แอป (SpiritVale Drops Overlay.exe)
  3) เปิดเกม SpiritVale -> overlay จะโชว์ของแรร์ที่ "เราฆ่าเอง" ดรอป + มีเสียง

การใช้งาน overlay:
  - ลากแถบหัวเพื่อย้าย
  - สไลเดอร์ = ปรับความโปร่ง (opacity)
  - ปุ่ม ▁ = ย่อ/ขยาย
  - ลากมุมขวาล่าง = ปรับขนาด
  - คลิกปรับได้ตลอด โดยไม่แย่งโฟกัสเกม
